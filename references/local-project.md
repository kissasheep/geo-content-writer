# Local GEO project discovery

Use this reference when the skill is installed inside a GEO content workspace. Do not assume a fixed drive letter, user name, or repository path.

## Discover the working locations

1. Start from the current workspace root or the nearest parent containing `.agents/skills/geo-content-writer`.
2. Locate the user-named brand folder, question library, source-material folder, and raw-image folder by name and contents.
3. Common Chinese workspace names include `资料`, `品牌门店档案`, `问题池`, `图片`, `原图`, `素材`, `成稿`, and `待确认`, but none is mandatory.
4. Keep the installed skill directory separate from source material and generated question packages.

Do not choose an input or output folder merely because its name contains `GEO`. Identify the user-named brand, question library, source folder, and image folder before writing. Treat folders marked `已用`, `成稿`, `重制`, `待确认`, `预览`, or `检测` according to their names and never merge them automatically.

## Safe working rules

- Read existing source and output conventions in the selected brand or task folder before creating files.
- Use only the specific question library, evidence files, and real-image directory identified for the current task.
- Never move, rename, edit, or deduplicate files in a source-image folder.
- Do not overwrite an existing article or completed package without first presenting the intended changes or saving a clearly named review draft.
- For a new package, use a new descriptive folder under the project root or the user-selected brand folder. Keep draft, preview, and final states visibly distinct.
- Preserve unrelated folders and files.

The user may add future brands or question banks. Discover them from the current project state instead of treating this profile as a complete inventory.
